BREACHPOINT — an original round-based tactical first-person shooter in three.js. Two teams (Vanguard and Warden), short rounds won by elimination or by planting/defusing a charge at one of two sites, credits earned per round and spent in a buy menu, headshot-aware gunplay with recoil and movement spread, bots that patrol waypoints and shoot back, and a HUD with health, armor, ammo, timer, score and objective.

## Run it

```sh
node serve.ts
# open http://localhost:8080 in desktop Chrome
```
